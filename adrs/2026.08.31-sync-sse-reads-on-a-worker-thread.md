# Sync SSE reads on a worker thread so Ctrl-C works

Date: 2026.08.31

Status: Accepted

## Context

A blocking sync read can't be interrupted, so Ctrl-C didn't stop a sync `sse()` loop.

## Decision

The sync client reads SSE chunks on a worker thread by default, switchable with the sync-only `interruptible=`.

## Consequences

`interruptible=` is an allowlisted difference in the sync/async parity test.
