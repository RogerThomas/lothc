# Make lothc backend-agnostic

Date: 2026.08.18

Status: Superseded by [Build on pyreqwest as the only backend](./2026.08.18-build-on-pyreqwest-as-the-only-backend.md)

## Context

lothc was conceived as one typed API over several existing Python HTTP clients.

## Decision

httpx, aiohttp, niquests and pyreqwest would be interchangeable underneath the same typed lothc interface.

## Consequences

Every feature would have been limited to what all four backends could do. It was never built in this repo: the first commit already uses pyreqwest alone.
