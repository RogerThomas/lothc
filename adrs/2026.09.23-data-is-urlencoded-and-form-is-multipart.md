# `data=` is urlencoded and `form=` is multipart

Date: 2026.09.23

Status: Accepted

## Context

Callers port code from requests and httpx.

## Decision

`data=` sends `application/x-www-form-urlencoded` and `form=` sends `multipart/form-data`, as requests and httpx mean those words. `parts=`, `multipart=` and `xform=`/`mform=` were rejected.

## Consequences

"data" also names response bodies (`Response.data`), accepted as the cost.
