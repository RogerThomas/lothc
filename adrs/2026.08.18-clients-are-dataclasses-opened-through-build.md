# Clients are dataclasses opened through `build()`

Date: 2026.08.18

Status: Reversed by [Clients are constructed directly and opened as context managers](./2026.09.23-construct-clients-directly-open-as-context.md)

## Context

The style guide prefers `@dataclass` for class definitions.

## Decision

`HTTPClient`/`SyncHTTPClient` are `@dataclass`es holding a pyreqwest `Client`, created by a `build()` classmethod and used as a context manager.

## Consequences

The constructor takes a pyreqwest `Client`, which puts a pyreqwest type in lothc's public API.
