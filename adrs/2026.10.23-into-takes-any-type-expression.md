# `into=` takes any type expression

Date: 2026.10.23

Status: Accepted

## Context

`into=` replaced `response_data_type=` (at first `data_type=`), where a target like a top-level array needed a `TypeAdapter` or `Decoder` wrapper (accepted on every verb from 2026.09.23).

## Decision

`into=` takes any PEP 747 `TypeForm`, so `get(path, into=list[User])` is typed `Response[list[User]]`, and the form is resolved to a decoder before sending. `typing-extensions` became a runtime dependency.

## Consequences

A bad target is a `TypeError` before any request is sent, and a pre-built `TypeAdapter`/`Decoder` still works.
