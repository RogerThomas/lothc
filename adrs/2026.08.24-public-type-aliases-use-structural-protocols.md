# Public type aliases use structural Protocols

Date: 2026.08.24

Status: Accepted

## Context

With an extra missing, strict checkers showed `Unknown` on unrelated public overloads.

## Decision

Public aliases refer to `Protocol`s (`StructTyping`, `BaseModelTyping`, ...) that import nothing; runtime dispatch still uses the real classes.

## Consequences

Consumers without pydantic or msgspec still get fully typed overloads, and a few `match` sites need an explicit narrowing guard.
