# Overloads instead of one generic signature with casts

Date: 2026.08.18

Status: Accepted

## Context

A single generic method with a value default was tried first, and it forced `cast()` at every internal branch.

## Decision

Each verb has one `@overload` per kind of decode target, plus one non-generic implementation that never claims to return the type parameter.

## Consequences

There are almost no casts, at the cost of many overloads per verb, whose order matters to some checkers.
