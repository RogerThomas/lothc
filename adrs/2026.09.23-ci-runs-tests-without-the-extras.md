# CI runs the extras-free tests without pydantic or msgspec

Date: 2026.09.23

Status: Accepted

## Context

The main test job always has both installed, so it would miss an unguarded import.

## Decision

`task test-no-extras` runs every test module that never mentions pydantic or msgspec with both uninstalled (`--no-install-package`, then `uv run --no-sync`).

## Consequences

`tests/_helpers.py` must stay free of both, since modules are picked by grepping their own text.
