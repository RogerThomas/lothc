# Publishing is dispatched against the tag

Date: 2026.09.28

Status: Accepted

## Context

A release created with `GITHUB_TOKEN` doesn't start other workflows, so release-please's release can't trigger `release.yml`.

## Decision

`release-please.yml` runs `gh workflow run release.yml --ref <tag>`. Dispatching rather than `workflow_call` keeps `release.yml` the top-level workflow PyPI's Trusted Publisher is registered against.

## Consequences

A failed publish is re-run with the same command, and `release.yml` refuses a non-tag ref.
