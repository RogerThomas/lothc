# Per-test server state is keyed by a fresh `server_key`

Date: 2026.10.23

Status: Accepted

## Context

The test server lives for the session, so hand-picked keys collided when copy-pasted and leaked state into re-runs.

## Decision

Every per-key server state uses the `server_key` fixture (a fresh `uuid4`), and OAuth tests use `token_server`.

## Consequences

A second key is a suffix of the first (`f"{server_key}-api"`).
