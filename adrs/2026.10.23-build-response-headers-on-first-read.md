# Build `Response.headers` on first read

Date: 2026.10.23

Status: Accepted

## Context

Converting headers eagerly cost ~2.7us per request, about 15% of lothc's throughput, and most callers never read them.

## Decision

`Response.headers` holds pyreqwest's `HeaderMap` and builds the `CaseInsensitiveDict` on first access, after which it is a plain one.

## Consequences

Unread headers cost 0.17us. It holds the `HeaderMap`, not the response, so held headers don't keep a read body alive.
