# `OAuthTokenError` wraps everything renewal raises

Date: 2026.09.07

Status: Accepted

## Context

Renewal runs inside the caller's own verb call, so its errors looked like the request's.

## Decision

Wrap every renewal failure in `OAuthTokenError`, with `.token_url` and the original as `__cause__`.

## Consequences

Callers can tell an auth failure from a request failure.
