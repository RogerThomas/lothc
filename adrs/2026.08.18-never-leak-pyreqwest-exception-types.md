# Never leak pyreqwest's exception types

Date: 2026.08.18

Status: Accepted

## Context

Callers would have to import the backend to catch lothc's errors.

## Decision

pyreqwest's transport errors are translated in one place to lothc's own (`HTTPTransportError` and its subclasses). From 2026.11.10, a `BuilderError` on client entry is a plain `ValueError`.

## Consequences

Every new pyreqwest error needs a mapping in `_translate_transport_error`, not at a call site.
