# Every non-streaming verb returns a `Response`

Date: 2026.09.25

Status: Accepted

## Context

This reversed [Verbs return the decoded body](./2026.08.18-verbs-return-the-decoded-body.md) and replaced [`client.with_result.<verb>` returns status and headers](./2026.09.23-with-result-returns-status-and-headers.md): lothc is a general-purpose client, not an SDK for one known API, and most callers need status and headers.

## Decision

Every body verb returns a `Response`, as requests, httpx, aiohttp and axios do; `Result` became `Response` and `with_result` was deleted. `download()` followed on 2026.09.28 (`Response[bytes]`, or `Response[Path]` with `dest=`).

## Consequences

Callers write `.data` for the body, and no flag switches the return type.
