# pydantic models encode by alias

Date: 2026.09.23

Status: Accepted

## Context

A camelCase pydantic model went back to the API as snake_case, unlike msgspec's `rename=`.

## Decision

Encode a model the way its own `serialize_by_alias` says (default `True`), at every encode site.

## Consequences

lothc never contradicts the model's own `model_dump()`.
