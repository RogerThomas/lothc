# release-please cuts releases from Conventional Commits

Date: 2026.09.28

Status: Accepted

## Context

This replaced [`task release` creates the GitHub Release that publishes](./2026.08.21-task-release-creates-the-github-release.md) and the hand-written Keep a Changelog `CHANGELOG.md` (0.0.17 to 0.0.19).

## Decision

Each push to `main` updates a release PR that bumps the manifest and prepends a changelog entry; merging it tags the release. Tags are the bare version: with the component, release-please looked for `lothc-0.0.19` and missed the real tag.

## Consequences

Commit messages on `main` must be Conventional Commits, and the release PR gets no CI run of its own, so `release.yml` runs `ci.yml` against the tag.
