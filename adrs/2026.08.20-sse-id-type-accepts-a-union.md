# SSE `id_type=` accepts a union such as `int | None`

Date: 2026.08.20

Status: Reversed by [SSE ids take `id_type=` plus `allow_missing_id=`](./2026.08.24-sse-ids-take-id-type-plus-allow-missing-id.md)

## Context

Not recorded.

## Decision

`sse(id_type=...)` takes a union, so `int | None` means an int id or none, replacing `id_type` plus a separate `require=` presence check.

## Consequences

Only basedpyright could type it; mypy, ty and zuban couldn't.
