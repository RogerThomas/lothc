# Support Python 3.13 and later only

Date: 2026.08.18

Status: Accepted

## Context

Not recorded.

## Decision

`requires-python = ">=3.13"`.

## Consequences

The code uses PEP 695 generics and PEP 696 defaults freely. On 3.13 annotations are evaluated eagerly, so a class used in one must be defined above it.
