# `invalidate()` marks the cached OAuth token expired on disk

Date: 2026.10.23

Status: Accepted

## Context

Only memory was cleared, so after a revocation every new process reloaded the dead token, and a POST's 401 is never retried.

## Decision

`invalidate()` marks the cache file's token expired if it still holds the rejected one, and a refresh that gets a 401, like a 400, falls back to minting.

## Consequences

The next process can still use the refresh token, and a revoked refresh token can't wedge every process sharing the cache.
