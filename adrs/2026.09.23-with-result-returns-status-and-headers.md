# `client.with_result.<verb>` returns status and headers

Date: 2026.09.23

Status: Superseded by [Every non-streaming verb returns a `Response`](./2026.09.25-every-non-streaming-verb-returns-a-response.md)

## Context

This replaced [Add `<verb>_result` twins for status and headers](./2026.08.23-add-verb-result-twins.md), which read wrong. A flag would have made the return type depend on a runtime `bool`, which overloads can't follow.

## Decision

One namespace, `client.with_result`, mirrors every verb and returns a `Result`, as the OpenAI and Anthropic SDKs do; the plain verbs keep returning the body.

## Consequences

Shipped in 0.0.17. Every verb is reachable two ways.
