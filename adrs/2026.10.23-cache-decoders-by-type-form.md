# Cache decoders by type form

Date: 2026.10.23

Status: Accepted

## Context

Building a pydantic `TypeAdapter` costs ~31us, on every call that names the form.

## Decision

Cache one decoder per form, except forms whose `Annotated` metadata compares by identity, which would grow the cache forever. 4096 entries is the backstop; once full, new forms decode uncached.

## Consequences

`list[User]` written inline on every call is one entry; an inline `Field(...)` form is rebuilt per call, so the docs say to hoist it into a `type` alias.
