# `tests/` type-checks under mypy, ty and zuban too

Date: 2026.08.24

Status: Accepted

## Context

A heavily overloaded generic API can satisfy one checker's inference and trip another's.

## Decision

`tests/`, which uses the public API as a consumer would, must pass mypy, ty and zuban as well as basedpyright.

## Consequences

A disagreement a real user would hit is fixed in the API, not suppressed; a scoped ignore is only for scaffolding no consumer could write.
