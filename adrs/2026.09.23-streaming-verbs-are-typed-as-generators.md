# Streaming verbs are typed as generators

Date: 2026.09.23

Status: Accepted

## Context

An `Iterator` return type hid `close()`/`aclose()`, and an async generator abandoned by `break` stays open until the loop's finalizer runs.

## Decision

Type `sse`, `stream_get` and `stream_post` as `Generator`/`AsyncGenerator`.

## Consequences

Callers can close a stream early, and the server sees the hang-up (`tests/test_stream_close.py`).
