# OAuth expiry is wall-clock, with a clamped leeway

Date: 2026.09.07

Status: Accepted

## Context

A cached token is read back by later processes, and a 300s leeway against a 60s token was expired at birth.

## Decision

Expiry is wall-clock time, stored as ISO 8601. `refresh_leeway` is clamped to half the lifetime, `default_expires_in` covers a missing `expires_in`, and a failed refresh falls back to minting on a 400 (`invalid_grant`).

## Consequences

A revoked refresh token costs one extra token request, not a failure.
