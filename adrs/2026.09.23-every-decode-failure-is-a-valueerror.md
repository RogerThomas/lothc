# Every decode failure is a `ValueError`

Date: 2026.09.23

Status: Accepted

## Context

Decode failures come from malformed JSON, the decode libraries, and a `dict` target given a non-object body.

## Decision

Every one is a `ValueError` (pydantic's and msgspec's errors already are), including a `dict` target given a JSON array.

## Consequences

Callers catch one exception type for a bad body.
