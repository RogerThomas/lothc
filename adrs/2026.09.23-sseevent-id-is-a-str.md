# `SSEEvent.id` is a `str`, `""` when absent

Date: 2026.09.23

Status: Accepted

## Context

This replaced [SSE ids take `id_type=` plus `allow_missing_id=`](./2026.08.24-sse-ids-take-id-type-plus-allow-missing-id.md), whose default required an id and failed on the first event from most real servers. Allowing a missing id by default (a same-day intermediate) still cost twelve overloads per client and a second type parameter.

## Decision

`SSEEvent[TData]` has `id: str = ""` and no id options, as the spec's last-event-id buffer and a browser's `lastEventId` do.

## Consequences

Callers convert with `int(event.id)`, and an empty id sends no `Last-Event-ID`.
