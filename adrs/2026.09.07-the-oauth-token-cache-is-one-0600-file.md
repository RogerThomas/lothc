# The OAuth token cache is one `0600` file

Date: 2026.09.07

Status: Superseded by [The OAuth token cache is one `0600` plaintext file per URL, client and scope](./2026.09.25-oauth-token-cache-is-one-file-per-scope.md)

## Context

Not recorded.

## Decision

`token_cache_path` names one file, written atomically via `mkstemp` with mode `0600`.

## Consequences

One file holds one token, for one token URL, client and scope.
