# In `form=`, a tuple repeats a part and a list is one JSON part

Date: 2026.08.23

Status: Accepted

## Context

An unsupported `form=` value fell through with no error.

## Decision

A tuple value repeats the part name once per element, a list is sent as one JSON part, and anything unmatched raises `TypeError`.

## Consequences

A list and a tuple mean different things in `form=`, unlike in `Params`.
