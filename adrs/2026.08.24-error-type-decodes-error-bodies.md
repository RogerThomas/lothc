# `error_type=` decodes error bodies onto `.parsed_body`

Date: 2026.08.24

Status: Superseded by [`error_type` decoding is best-effort](./2026.09.23-error-type-decoding-is-best-effort.md)

## Context

APIs return structured error bodies with a 4xx/5xx.

## Decision

A per-call `error_type=` decodes a 4xx/5xx body onto `HTTPResponseError.parsed_body`, and a body that doesn't match propagates the decode library's exception.

## Consequences

`.parsed_body` is untyped, and a mismatched error body hides the status error.
