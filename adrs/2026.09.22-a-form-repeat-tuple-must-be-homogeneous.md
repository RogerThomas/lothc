# A `Form` repeat tuple must be homogeneous

Date: 2026.09.22

Status: Accepted

## Context

A mixed tuple such as `(b"...", "image/png")` read as a file plus its content type but had no filename, and went out as two parts.

## Decision

A repeat tuple is all text, all bytes, all files or all JSON, enforced by the types and at runtime, and a list is always one JSON part, even when it looks like a file.

## Consequences

Only a `Path` carries its own filename, so `tuple[Path, str]` is a file and `tuple[bytes, str]` isn't.
