# Build on pyreqwest as the only backend

Date: 2026.08.18

Status: Accepted

## Context

This replaced [Make lothc backend-agnostic](./2026.08.18-make-lothc-backend-agnostic.md): there was no compelling reason not to just use pyreqwest.

## Decision

lothc is built on pyreqwest alone. An httpx, aiohttp or niquests backend would be added only if someone asks for one.

## Consequences

Wherever lothc doesn't override it, its behaviour is pyreqwest's, and the other clients appear only as benchmark comparisons.
