# The version comes from the git tag

Date: 2026.08.21

Status: Accepted

## Context

A static version means remembering to bump and commit it before tagging.

## Decision

`hatch-vcs` derives the version (`dynamic = ["version"]`): a release is a tag, with nothing bumped by hand.

## Consequences

The version exists only in git, and `pyproject.toml` never changes for a release.
