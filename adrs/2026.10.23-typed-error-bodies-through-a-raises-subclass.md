# Typed error bodies through a `raises=` subclass

Date: 2026.10.23

Status: Accepted

## Context

This replaced [`error_type` decoding is best-effort](./2026.09.23-error-type-decoding-is-best-effort.md), whose `.parsed_body` was untyped. Python can't `except` a parametrized generic, so `E` must live on a real class.

## Decision

`raises=` takes a subclass pinning `HTTPResponseError[E]`, resolved before sending. Decoding stays best-effort, and a `RecursionError` or `TypeError` from the body is wrapped in a `ValueError` on `.parse_error`.

## Consequences

`.error` is typed `E | dict[str, Any] | None` in the `except`, and a bad class fails before sending, not on the first real 4xx.
