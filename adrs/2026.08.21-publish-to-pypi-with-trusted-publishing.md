# Publish to PyPI with Trusted Publishing

Date: 2026.08.21

Status: Accepted

## Context

Publishing from CI would otherwise need a stored PyPI token.

## Decision

`release.yml` runs `uv publish` through Trusted Publishing (OIDC, the `pypi` environment, no token). The environment is left without tag protection, to be set in the GitHub UI, since a misconfigured policy could silently block releases.

## Consequences

Until that protection is added (a TODO in `CLAUDE.md`), anyone who can start a release can publish.
