# A list in `Params` repeats the key

Date: 2026.09.11

Status: Accepted

## Context

APIs take repeated query keys (`?tag=a&tag=b`).

## Decision

A `list` or `tuple` value repeats the key once per element; both spellings work.

## Consequences

`_query_pairs` flattens to pairs first, since pyreqwest's `.query()` rejects a list value despite its stub.
