# `base_url` joins per RFC 3986

Date: 2026.09.23

Status: Accepted

## Context

Callers need a predictable rule for combining `base_url` with a verb's path.

## Decision

Join as pyreqwest does: a leading `/` drops the base's path, and an absolute or protocol-relative URL replaces the base, auth headers included.

## Consequences

`base_url` must end in `/` when it has a path, and that's checked at construction.
