# OAuth token requests are urlencoded, with lothc's own Basic header

Date: 2026.09.07

Status: Accepted

## Context

RFC 6749 §2.3.1 encodes client credentials differently from `quote_plus`.

## Decision

Token requests are `application/x-www-form-urlencoded` (through `data=` from 2026.09.23), and lothc builds the Basic header itself, `quote(..., safe="")` per half, not through the internal client's `basic_auth=`.

## Consequences

Credentials with spaces or reserved characters authenticate correctly.
