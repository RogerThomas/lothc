# README.md uses absolute URLs only

Date: 2026.09.23

Status: Accepted

## Context

README.md is the PyPI description, and PyPI can't resolve repo-relative paths.

## Decision

Images come from `raw.githubusercontent.com/.../main/`, docs from `rogerthomas.github.io/lothc/<page>/`, other files from `github.com/.../blob/main/`.

## Consequences

A PyPI description is frozen per release, so a README fix shows only after the next one.
