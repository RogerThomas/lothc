# lothc gives pyreqwest a requests-shaped API and typed bodies

Date: 2026.08.23

Status: Accepted

## Context

pyreqwest's builder API is unlike the requests/httpx calls most Python code uses, and a bare `dict` body is neither validated nor typed.

## Decision

lothc wraps pyreqwest in requests/httpx-shaped calls and decodes bodies into validated, typed targets.

## Consequences

Open API choices lean on requests/httpx precedent, as `data=` and `form=` do.
