# Add `<verb>_result` twins for status and headers

Date: 2026.08.23

Status: Superseded by [`client.with_result.<verb>` returns status and headers](./2026.09.23-with-result-returns-status-and-headers.md)

## Context

Only `get()` had a status-and-headers form, `get_result()` (see [Verbs return the decoded body](./2026.08.18-verbs-return-the-decoded-body.md)).

## Decision

`post_result`, `put_result`, `patch_result` and `delete_result` mirror `get_result`.

## Consequences

Every body verb has two public methods with different return shapes.
