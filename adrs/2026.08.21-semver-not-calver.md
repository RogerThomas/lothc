# SemVer, not CalVer

Date: 2026.08.21

Status: Accepted

## Context

This replaced [CalVer, derived from the git tag](./2026.08.18-calver-derived-from-the-git-tag.md): lothc is a library other packages depend on.

## Decision

lothc's versions are SemVer.

## Consequences

Dependants get the major/minor/patch signal, unlike yeetr's CalVer.
