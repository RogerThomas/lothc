# SSE ids take `id_type=` plus `allow_missing_id=`

Date: 2026.08.24

Status: Superseded by [`SSEEvent.id` is a `str`, `""` when absent](./2026.09.23-sseevent-id-is-a-str.md)

## Context

This replaced [SSE `id_type=` accepts a union such as `int | None`](./2026.08.20-sse-id-type-accepts-a-union.md), which only basedpyright could type.

## Decision

Two plain knobs: `id_type=` coerces the id, and `allow_missing_id=False` requires one.

## Consequences

Identical precision on all four checkers, at the cost of extra overloads per id option.
