# `lothc.testing` exposes no pyreqwest type and no builder

Date: 2026.09.10

Status: Accepted

## Context

pyreqwest's own mocking is configured through its `ResponseBuilder`, which would put pyreqwest in lothc's API.

## Decision

Handlers return a `MockResponse` dataclass and see a `MockRequest`, and matching reuses the real request path's encoders.

## Consequences

A mock matches exactly what would be sent, and `_mock_request_from` is the only code touching pyreqwest's `Request`.
