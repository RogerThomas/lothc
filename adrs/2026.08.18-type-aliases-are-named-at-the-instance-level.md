# Type aliases are named at the instance level

Date: 2026.08.18

Status: Accepted

## Context

Not recorded.

## Decision

`Data`, `Params`, `Headers`, `Form`, `File` and the JSON alias name what a value is, not its class. The JSON one became `JSONPayload` on 2026.08.21, avoiding a case-only clash with the `JSON` class.

## Consequences

New aliases follow the same naming.
