# Verbs return the decoded body

Date: 2026.08.18

Status: Reversed by [Every non-streaming verb returns a `Response`](./2026.09.25-every-non-streaming-verb-returns-a-response.md)

## Context

Not recorded.

## Decision

Each verb returns its body (raw `bytes` by default), and `get_result()` returns a `Result` with status and headers as the escape hatch. The earlier `Response`/`SyncResponse` wrappers were deleted.

## Consequences

Status and headers are reachable only through `get_result()`.
