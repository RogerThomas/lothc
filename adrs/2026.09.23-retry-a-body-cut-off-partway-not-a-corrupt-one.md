# Retry a body cut off partway, not a corrupt one

Date: 2026.09.23

Status: Accepted

## Context

pyreqwest reports a body shorter than its `Content-Length` and a corrupt gzip body with the same error type.

## Decision

Retry a decode error only when a cause is hyper's "error reading a body from connection".

## Consequences

A flaky connection recovers, and a broken server isn't hammered.
