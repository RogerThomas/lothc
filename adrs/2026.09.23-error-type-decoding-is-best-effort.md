# `error_type` decoding is best-effort

Date: 2026.09.23

Status: Superseded by [Typed error bodies through a `raises=` subclass](./2026.10.23-typed-error-bodies-through-a-raises-subclass.md)

## Context

This replaced [`error_type=` decodes error bodies onto `.parsed_body`](./2026.08.24-error-type-decodes-error-bodies.md), where an error body that didn't match hid the status error.

## Decision

A decode failure goes on `.parse_error`, and the status error is raised as usual.

## Consequences

A proxy's HTML 502 still surfaces as a 502, though `.parsed_body` stays untyped.
