# The sdist has an explicit include allowlist

Date: 2026.08.21

Status: Accepted

## Context

hatchling's sdist default is everything under version control, so 0.0.1's sdist shipped the whole repo (420KB vs 15.7KB).

## Decision

`[tool.hatch.build.targets.sdist]` includes only `/lothc`, `/README.md` and `/LICENSE`. The wheel needs no list.

## Consequences

A new top-level file the sdist needs must be added to the list. 0.0.1 wasn't yanked: it had no functional impact.
