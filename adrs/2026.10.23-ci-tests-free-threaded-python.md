# CI tests free-threaded Python with the GIL off

Date: 2026.10.23

Status: Accepted

## Context

lothc keeps process-wide state shared across threads (the decoder and `raises=` caches, lazy headers), and users share one client across threads. CI had run 3.13 and 3.14 since 2026.08.21.

## Decision

CI adds 3.15 and free-threaded 3.14t/3.15t, with `PYTHON_GIL=0` and an assertion that the GIL really is off.

## Consequences

The comparison clients moved to their own `perf` group, since niquests → urllib3-future → qh3 has no free-threaded 3.15 wheel.
