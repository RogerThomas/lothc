# Clients are constructed directly and opened as context managers

Date: 2026.09.23

Status: Accepted

## Context

This reversed [Clients are dataclasses opened through `build()`](./2026.08.18-clients-are-dataclasses-opened-through-build.md), whose constructor took a pyreqwest `Client`.

## Decision

`__init__` takes only lothc settings and validates them, a bad `base_url` included. Each `async with`/`with` builds a fresh pyreqwest client, reachable only while open, and no pyreqwest type appears in the public API (`tests/test_public_api.py`).

## Consequences

Mistakes fail where the client is created, and a client is re-enterable, so a module-level one works across `asyncio.run()` calls. Not being dataclasses is a deliberate style-guide exception.
