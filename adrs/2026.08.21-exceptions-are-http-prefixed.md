# Exceptions are `HTTP`-prefixed

Date: 2026.08.21

Status: Accepted

## Context

Not recorded. This replaced [Transport errors shadow the builtin exception names](./2026.08.18-transport-errors-shadow-the-builtin-names.md).

## Decision

`HTTPTransportError`, `HTTPTimeoutError`, `HTTPConnectionError` and `HTTPResponseError`.

## Consequences

lothc's names no longer shadow the builtins.
