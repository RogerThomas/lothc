# The OAuth token cache is one `0600` plaintext file per URL, client and scope

Date: 2026.09.25

Status: Accepted

## Context

This replaced [The OAuth token cache is one `0600` file](./2026.09.07-the-oauth-token-cache-is-one-0600-file.md): one client ID can serve several token URLs or scopes.

## Decision

`token_cache_dir` holds one file per token URL, client ID and scope, written atomically with mode `0600`. Not encrypted: a key derived from the client secret protects little, since the secret can mint tokens itself, and the AWS CLI and gcloud also use `0600` plaintext.

## Consequences

Anyone who can read the file can use its token until it expires.
