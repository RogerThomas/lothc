# Re-authenticate once on a 401

Date: 2026.09.23

Status: Accepted

## Context

An OAuth token revoked early kept failing every call until it expired.

## Decision

On a 401, invalidate the rejected token through any `bearer_auth` that can `invalidate()`, and retry once, for idempotent verbs only. Invalidating a token the provider has already replaced is a no-op.

## Consequences

Concurrent 401s can't discard each other's fresh token, and a POST is never replayed.
